# Building, flashing and testing

[Français](../fr/building.md) · English

## Requirements

- **ESP-IDF 5.5.6** (target `esp32s3`). It is the version the firmware is built and tested
  with, and the one CI uses.
- LVGL **9.2.2**, fetched by the ESP-IDF component manager (`main/idf_component.yml`).
- Python 3 and gcc for the PC tests.

## Build

```bash
idf.py set-target esp32s3          # once
idf.py build
idf.py -p /dev/ttyACM0 flash monitor
```

`idf.py flash` also writes the emoji pack (`assets/emoji.bin`) to its partition.

Options, as environment variables at build time:

| Variable | Effect |
|---|---|
| `TW_EXTRA_COMPONENT_DIRS=/path` | extra component directory (e.g. a local LVGL copy for offline builds, with `IDF_COMPONENT_MANAGER=0`) |
| `TW_DIAG_BLE_ONLY=1`, `TW_DIAG_BARE=1` | diagnostic builds (BLE only / no peripherals) |

After **any change to `sdkconfig.defaults`**, delete the generated `sdkconfig` (keep
`sdkconfig.defaults`) and rebuild; otherwise the old values stay.

## Flash layout (16 MB)

| Offset | Size | Content |
|---|---|---|
| `0x0` | | bootloader (with app rollback) |
| `0x8000` | | partition table |
| `0x9000` | 24 KB | NVS (settings, pairings, battery history, steps, Púca…) |
| `0xf000` | 4 KB | PHY calibration |
| `0x10000` | 8 KB | OTA data (which slot boots) |
| `0x20000` | 5 MB | `ota_0` |
| `0x520000` | 5 MB | `ota_1` |
| `0xa20000` | 3 MB | `emoji`: colour emoji pack (not touched by Wi-Fi updates) |
| `0xd20000` | 64 KB | core dump |
| `0xd30000` | 2.8 MB | `storage` (FAT) |

## Flashing

**First install** (erases everything, pairings included):

```bash
esptool.py --chip esp32s3 -b 921600 write_flash 0x0 twatch-ultra-full.bin
```

**Over USB while keeping pairings and settings**:

```bash
esptool.py --chip esp32s3 -b 921600 write_flash \
  0x0 bootloader.bin 0x8000 partition-table.bin \
  0x10000 ota_data_initial.bin 0x20000 twatch-ultra-app.bin 0xa20000 emoji.bin
```

`ota_data_initial.bin` makes the watch boot `ota_0`, where the application is written.

**Over the air**: see the README (*Settings › Update*). The update page is served by the
watch itself at `http://192.168.4.1`; it follows the browser language (French or English).
The check refuses images from another project (the 2020 firmware, for instance).

## Release binaries (CI)

`.github/workflows/build.yml` runs the PC tests and the firmware build on every push. On a
`v*` tag it publishes:

- `twatch-ultra-full.bin` — complete image for `0x0`, emoji pack included;
- `twatch-ultra-app.bin` — application only (Wi-Fi update or USB at `0x20000`);
- `LICENSE` and `THIRD_PARTY_NOTICES.md`.

The workflow artifact also contains the bootloader, partition table, OTA data, emoji pack and
the ELF (for decoding crashes).

## Versions

The version is `PROJECT_VER` in `CMakeLists.txt`; the watch shows it in *Settings › About*.
Every test build handed out bumps the last number and gets a
`CHANGELOG.md` entry, and its application image is named `twatch-ultra-X.Y.Z.bin`, so two
test images never carry the same name. A release is the `vX.Y.Z` tag of that version.

## PC tests

```bash
host_tests/run.sh
```

Runs, under AddressSanitizer and UBSan:

- the ANCS parser (10,000 random fragmentations of the Data Source stream), UTF-8 cleanup
  (emoji kept, unsupported scripts dropped, overlong forms and surrogates rejected),
  notification store (dedup, sort, capacity);
- the Púca model (growth, sleep, neglect, steps → shamrocks);
- `check_i18n.py`: every `_()`/`N_()` string has an English translation with the same printf
  specifiers in the same order.

## Debugging

- **Crash**: the core dump is kept in flash. `esp-coredump info_corefile build/twatch_ultra.elf`.
- **BLE without a computer**: *Settings › About* shows a time-stamped BLE log, wake-up
  counters, heap, PSRAM and power-rail registers.
- **Battery**: *Battery* screen (gauge, estimated average consumption, previous discharge).

## Fonts and emoji

`main/fonts/` is generated by `tools/gen_fonts.py` (needs
[lv_font_conv](https://github.com/lvgl/lv_font_conv), fontTools and an LVGL 9.2.2 checkout
for the Montserrat, DejaVu Sans and Font Awesome sources):

```bash
LVGL_DIR=/path/to/lvgl python3 tools/gen_fonts.py
```

It also writes `main/fonts/font_cov.c`, the list of characters the text fonts can draw, used
to clean up incoming text. To add an icon, append its Font Awesome code point to `FA_BASE`
(or define its UTF-8 sequence in `main/ui_kit.h`, which the script reads) and regenerate.

`assets/emoji.bin` is generated by `tools/gen_emoji.py` from the Twemoji 72×72 PNGs
(needs Pillow):

```bash
git clone --depth 1 https://github.com/jdecked/twemoji
TWEMOJI_DIR=twemoji/assets/72x72 python3 tools/gen_emoji.py
```
